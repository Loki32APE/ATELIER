ATELIER · DATA HANDLING

Privacy

What this app stores in your browser and what leaves the browser when you ask an AI feature to run.

ON THIS DEVICE

Saved workspace data

Preferences, creative profiles, saved prompts, projects, and saved reference-library images are kept in this browser's local storage or IndexedDB. This build does not sync them between devices. Remove them from Settings or the Library.

WHEN YOU GENERATE

Prompts and images

When you start generation, prompt details and any selected Studio reference images are sent to the Atelier server, then to the configured model through OpenRouter for processing. Visual Lab sends the brief text. The model provider receives and handles that request under its own policies.

TEMPORARY PROCESSING

Job records

The server temporarily keeps job status and results so the app can return them to you. In the standard configuration, finished records are cleaned up after about one hour. Queue payloads have a default 24-hour lifetime; the server operator can change it. Hosting operators may have separate infrastructure logs and backups.

CREDENTIALS

Provider keys

Provider credentials are configured on the server and are not stored in browser settings. Never put API keys, passwords, or other secrets into a prompt or image.

YOUR CHOICE

Use only what you are comfortable sharing

You can use the Library and build prompts without starting an AI request. Before using generation or image analysis, consider whether the prompt and reference images are appropriate to send to the configured model provider.
