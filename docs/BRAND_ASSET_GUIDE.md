# Atelier Prompt Engine — Brand Asset Guide

## Approved direction
Follow the user's production assets pack exactly: **Darkroom Obsidian & Warm Archival Paper**, Editorial Vermilion, and the hollow multi-faceted wireframe “A” prism mark.

**Brand line:** Where Imagination Meets Intelligence.

## Colour palette
| Token | Hex | Intended use |
|---|---|---|
| Darkroom base | `#111215` | Dark canvas |
| Darkroom surface | `#181A1F` | Cards and panels |
| Darkroom elevated | `#20232A` | Raised surfaces |
| Darkroom input | `#14161B` | Editable controls |
| Darkroom border | `#2B2F38` | Hairline separators |
| Editorial Vermilion | `#E04F33` | Primary accent |
| Vermilion hover | `#C84127` | Accent hover state |
| Archival base | `#F6F4EF` | Light canvas |
| Archival surface | `#FFFFFF` | Cards and panels |
| Archival elevated | `#ECE9E1` | Raised surfaces |
| Archival input | `#FAF9F6` | Editable controls |
| Archival border | `#DCD8CE` | Hairline separators |
| Archival ink | `#16171A` | Primary light-mode text |

## Typography
- **Instrument Sans** — display headings.
- **Plus Jakarta Sans** — application UI and body copy.
- **JetBrains Mono** — prompt and technical content.

## Production files
- `static/css/brand-tokens.css` — dual-mode CSS variables and typography.
- `static/brand-tokens.json` — machine-readable brand specification.
- `static/brand/atelier-mark.svg` and `atelier-mark-archival.svg` — dark/light prism mark.
- `static/brand/atelier-wordmark.svg` and `atelier-wordmark-archival.svg` — themed wordmark lockups.
- `static/brand/icons.svg` — icon sprite from the supplied pack.
- `static/brand/atelier-app-icon.svg` — app and launcher mark.

The supplied HTML pack remains the untouched reference. Keep its selected colors, mark, and fonts unchanged when adapting them to the app's templates.
